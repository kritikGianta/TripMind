# request_classifier

Sorts a traveller's message into a support category (cancellation or refund, change a booking,
baggage and seats, check-in, flight status, insurance, new booking, existing booking, talk to a
person). Routes support tickets and helps the assistant.

- **Model:** TF-IDF + logistic regression, exported as JSON (no pickle); used when its top
  probability is at least 0.45, otherwise keyword rules decide.
- **Data:** Bitext travel customer-support dataset (`bitext/Bitext-travel-llm-chatbot-training-dataset`
  on Hugging Face, about 31,700 rows, 33 intents, CDLA-Sharing-1.0). The 33 intents map to
  TripMind categories in `backend/app/modules/ml/request_classifier.py` (`INTENT_CATEGORIES`).
- **Caveat:** the data is generated by Bitext, so its own test score is optimistic; the notebook
  also reports accuracy on hand-written messages.
- **Baseline:** the keyword rules in the same file. The notebook refuses a model that does not
  beat them.
- **Run:** locally or on Kaggle with internet; artifacts go in `artifacts/`.
